# Zenith Open Source Projects

> *"Open Source is the First Step of Development."*

**Zenith** is a digital portfolio and registry showcase for open‑source systems code, automation pipelines, civic‑tech tools, and developer utilities. Designed in India and built for the global developer ecosystem, this portfolio aggregates, visualizes, and monitors our development cadence and active repositories.

---

## ✦ Core Thesis

Every utility, pipeline, and helper project built under the **Zenith** umbrella is open-source by design. We focus on:
1. **Self-Reliance (Bharat First)**: Verifiable digital infrastructure, local data parsers, and custom utilities to empower students and system administrators.
2. **Transparent Architecture**: Deterministic builds, clear script flows, and readable documentation.
3. **Systems & Automation**: Low‑level utilities, bot configurations, and audio presets that simplify developer workflows.

---

## ✦ Built With

The portfolio is built using a modern, fast, and responsive frontend stack:
- **Core Framework**: [Next.js 16](https://nextjs.org/) (App Router & React 19)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with PostCSS configuration
- **Animations**: [Framer Motion](https://www.framer.com/motion/) for micro-interactions and smooth transitions
- **Icons**: [Lucide React](https://lucide.dev/)

---

## ✦ Key Features

- **Ecosystem Map**: An interactive filtering dashboard that groups and filters active projects by category (Civic‑tech, AI, Bots, Linux, Systems, Tools).
- **Engineering Telemetry**: A live commit cadence heatmap simulating deployment pipeline activities.
- **Terminal Scraper Simulator**: A mock real-time Sentinel compilation log simulating active web scrapes.
- **Responsive Layout**: Designed for high fidelity across mobile viewports, tablets, and ultra-wide screens.

## ✦ Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18.x or later) and `npm` installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/roshhellwett/zenithopensourceprojects.git
   cd zenithopensourceprojects
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

4. Build for production:
   ```bash
   npm run build
   ```
